## ملاحظات الذكاء في التحويل

- **Caps Lock تلقائي**: إذا كان حرف كبير يُعطي رمزاً غير عربي لكن نظيره الصغير يُعطي حرفاً عربياً، يُستخدم الصغير تلقائياً (مثل: `I` → `ه` بدل `÷`)
- **الأرقام تمر بدون تغيير**: `0-9` لا تتأثر بالتحويل
- **الرموز الشائعة تمر بدون تغيير**: `! @ # % - _ = + ( ) space`
- **الحروف المركّبة (Ligatures)**: `لا` `لأ` `لإ` `لآ` يُتعامل معها كوحدة واحدة
